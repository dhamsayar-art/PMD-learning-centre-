## Installation

1. Download the project.
2. Open the project folder.
3. Add your Firebase configuration in `firebase.js`.
4. Enable Authentication, Firestore and Storage in Firebase.
5. Run the project using a local server.

1. Create a Firebase Project.

3. Create a Firestore Database.
4. Enable Firebase Storage.
5. Replace the Firebase configuration in `js/firebase.js`.

# Firebase Hosting

Install Firebase CLI:

```bash
npm install -g firebase-tools
```

Login:

```bash
firebase login
```

Initialize:

```bash
firebase init
```

Deploy:

```bash
firebase deploy
```

# Security Checklist

- Enable Firebase Authentication.
- Configure Firestore Security Rules.
- Configure Firebase Storage Rules.
- Do not expose Firebase Admin SDK credentials.
- Restrict admin-only pages with authentication and authorization.

# Troubleshooting

### Images are not loading

- Verify the `images/` folder exists.
- Check image file names and extensions.

### Firebase is not connecting

- Verify the Firebase configuration.
- Ensure Firestore, Authentication and Storage are enabled.
- Check browser console for errors.

### Login is not working

- Confirm Email/Password Authentication is enabled.
- Check authentication rules and network connection.

### Data is not saving

- Verify Firestore permissions.
- Check collection names used in the code.
- Inspect browser console for Firebase errors.
